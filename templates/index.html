📚 How This System Works

Four domains working together in one integrated pipeline.

👁
Computer Vision — LSB Steganography

Every pixel has R, G, B values (0–255). We replace the Least Significant Bit of each channel with a secret message bit. Change is only ±1 — completely invisible to human eye.

Before: R=11001000 | After: R=11001001 (change = 1)
✨
Generative AI — Message Transformation

Plain text is transformed into a structured secure classified message with timestamps, protocol headers and cipher hints using the Anthropic Claude API before embedding.

📊
Data Science — Image Quality Metrics

MSE measures average pixel difference. PSNR measures quality in decibels. PSNR above 40 dB means visually identical. Our system achieves ~70 dB.

PSNR = 10 × log10(255² / MSE)
🧠
AI/ML — CNN Stego Detection

A CNN with 684,833 parameters trained on 8000 images detects hidden content with 84.4% confidence by learning subtle LSB noise patterns invisible to humans.
