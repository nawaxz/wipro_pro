📚 How This System Works
👁
Computer Vision — LSB Steganography

Every pixel has R, G, B values (0–255). We replace the last bit (Least Significant Bit) of each channel with a secret message bit. Change is only ±1 — invisible to human eye.

Before: R=11001000 | After: R=11001001 (change = 1)
✨
Generative AI — Message Transformation

Plain text is transformed into a structured secure classified message with timestamps, protocol headers and cipher hints before embedding.

📊
Data Science — Image Quality Metrics

MSE measures average pixel difference. PSNR measures quality in decibels. PSNR above 40 dB means the stego image is visually identical to original.

PSNR = 10 × log10(255² / MSE)
🧠
AI/ML — CNN Stego Detection

A Convolutional Neural Network trained on cover vs stego images detects hidden content by learning subtle statistical patterns that LSB modification creates.

📁
File Embedding — Extended Feature

Any file (PDF, DOCX, TXT) is converted to Base64 string, then embedded using LSB. On extraction, it is decoded back to original file for download.

File → Base64 String → LSB Embed → Stego Image
