📚 How XOR Secret Sharing Works
1️⃣
Message or File → Binary Bits

Text is converted to binary. Files are converted to Base64 string first, then to binary.

2️⃣
Generate 2 Random Shares

Two completely random bit sequences — meaningless alone.

Share1 = 10110101... (random noise)
3️⃣
Compute Share 3 using XOR

Share3 is calculated so XOR of all 3 equals original.

Share3 = Message ⊕ Share1 ⊕ Share2
4️⃣
Embed Each Share into an Image

Each share is hidden in a separate image using LSB steganography.

5️⃣
Reconstruct with All 3 Images

XOR all 3 extracted shares to perfectly recover original text or file.
